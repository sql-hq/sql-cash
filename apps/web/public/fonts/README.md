# Inter variable font

- Font: Inter, normal style, variable optical size and weight.
- Copyright: 2020 The Inter Project Authors (https://github.com/rsms/inter).
- Source: https://github.com/google/fonts/tree/main/ofl/inter
- Downloaded source: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
- Retrieved: September 6, 2026.
- License: SIL Open Font License 1.1, included as `Inter-OFL.txt`.

`InterVariable.ttf` is the unchanged upstream variable font, self-hosted so the interface does not contact an external font service. Inter is an open source substitute for the proprietary Arcadia fonts in the Mercury reference.
