# Contributing

Open a focused issue before a major change. Keep fixes small, add tests for changed behavior and describe how you verified them. Discuss cryptographic, contract and financial changes before implementation.

Use English for issues, documentation and pull requests. Preserve upstream license notices. Never submit credentials, recovery material or real user records. Report security issues privately to support@sql.cash, not in a public issue.

Repository links and release downloads are listed in README.md.
