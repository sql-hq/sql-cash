# Security

Report suspected vulnerabilities privately to **support@sql.cash**. Include affected versions, a minimal reproduction and impact. Do not send private keys, recovery phrases, vault passwords or unredacted user data.

A successful financial acceptance test is not an independent audit. Real external-wallet browser acceptance and a clean audit of all retained legacy development dependencies are not claimed. The active Ethereum mainnet financial path uses RAILGUN; retained SQL/NULL contracts are legacy Sepolia reference source.

Secrets belong in server-side environment variables. Never place paid RPC credentials or signing keys in browser-prefixed variables, commits, release files or issue reports. Source releases contain no operator wallets, private backups, deployment credentials or historical workspace commits.
